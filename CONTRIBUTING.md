# Contributing

Follow [AGENTS.md](AGENTS.md) for layout, writing, versioning, and validation.

Useful contributions include new self-contained research skills, fixes supported by reproducible examples, and checks that catch observed failures. Keep a pull request focused on the affected skill and related repository documentation.

Prepare its dependencies, run `python check.py`, and report the checks performed and any untested native environment. Preserve source attribution and third-party terms listed in [NOTICE.md](NOTICE.md). Domain-specific scope requirements remain in the relevant skill.
