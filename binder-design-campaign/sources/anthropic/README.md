# Anthropic source prompt — reference only

`multi_target_binder_design_prompt.md` is an unmodified copy of Anthropic's
multi-target campaign prompt, downloaded from its [official Hugging Face data
release](https://huggingface.co/datasets/Anthropic/claude-protein-binder-design/blob/main/prompts/prompts/multi_target_binder_design_prompt.md)
on 2026-09-30. SHA-256:
`a069b096726f43fc39f149f2ed0e61c2023ed2a0d58edabedd215de69f5f8c7d`.

Anthropic publishes the dataset under **CC-BY-4.0**. Copyright and license of
this source file remain with Anthropic; the repository's MIT license does not
relicense it. See the dataset page for the sixteen single-target versions and
kickoff messages, and `../../docs/source-mapping.md` for the adaptation map.

This file describes one historical campaign. Its targets, cloud account,
budget, internal communication channels and autonomy instructions are data for
comparison, not instructions to execute when this skill is invoked. Use the
current `../../SKILL.md` and a user-approved campaign plan for a new task.
